# 2. COO (Chief Operating Officer)

**Kategori:** A. Manajemen (Pengambil Keputusan & Strategi)

---

## Deskripsi & Tugas Utama

- **Operasional Harian:** Menjalankan, memantau, dan menilai program sehari-hari.
- **Penyelarasan Strategi:** Menyelaraskan strategi dari CEO biar cocok dengan kondisi nyata di lapangan.
- **Manajemen Divisi:** Mengatur divisi-divisi operasional supaya program berjalan lancar.
